# 术语表

散文（注释、文档、提交信息、文案）里首次出现一个术语时用 `[术语]` 标记，本文件必须有对应条目。

标识符直接用那个词的英文，不需要标记。

术语分两类：

- **借来的**：`Scope`、`Session`、`Message`、`Subscription`、FTS、WAL。业界已有，不解释，只在含义被本项目收窄时记一行。
- **产品自己的**：本文件的主体。这些概念必然存在，所以它们必须有唯一定义。

**一个概念只有一个名字。** 最后一列是不许用的叫法——它是禁用词的出处。

| 术语 | 标识符 | 定义 | 不许叫 |
|---|---|---|---|
| 项目 | `Workspace` | 一个工作目录及它的身份。一行记录，`cwd` 唯一 | 工作区、空间、repo |
| 会话 | `Session` | 一段持续的身份与历史。一行记录，永远存在 | 对话、聊天、thread、conversation |
| 消息 | `Message` | 会话里的一条内容（core 的类型），整条存在 `payload` | 话、聊天记录、条目 |
| 助手 | `AgentDefinition` | 用户配置里的模板：模型、参数、系统提示 | 智能体、agent（会与执行体混淆） |
| 执行体 | `Agent` | 一段会话上活着的那个对象，与会话 1:1，可能不存在 | 实例、机器人、worker、驱动者 |
| 能力容器 | `Scope` | 按目录存活，持有 MCP 连接、插件与工具；与项目 1:1 | 上下文、环境、沙箱 |
| 素材 | `Asset` | 上传的文件：库里的行 + 磁盘上的字节 | 附件、图片、文件 |
| 交接 | `Handoff` | 上下文装不下时换取新记忆的动作 | 迁移、归档、压缩（压缩是它的实现手段之一） |
| 提问 | `Question` | 宿主向用户发问并等待回答的进程内对象，不落库 | 询问、弹窗、确认框 |
| 通知 | `Notice` | 一条短消息，落库，有寿命 | 提示、toast |
| 递话 | `deliver` | 把一条内容交给执行体的 inbox；不会唤醒它 | 发送（那是客户端视角）、推送 |
| 发话 | `post` | agent 之间的一步：把一条话寄给另一段会话（模型那一侧的对应工具是 `post_message`） | 发送、通知、递话（那是往 inbox 放一条的那层） |
| inbox | `inbox` | 执行体取件的队列；未被取走的条目落库 | 消息队列、缓冲区、待处理 |
| 暂停 | `pause` | 关闭输出，不中止进行中的请求 | 停止、挂起 |
| 中断 | `abort` | 中止进行中的请求并关闭输出，不销毁执行体 | 取消、打断、停止 |
| 杀死 | `kill` | 销毁执行体；会话行与历史保留 | 关闭、结束、销毁 |
| 配置 | `config` | 磁盘上人可编辑的文件。既不是库里的行，也不是活物 | 设置、选项、偏好 |
| 凭证 | `credential` | 宿主访问令牌：落库、带 hash、可吊销 | 密钥（那是模型端点的 `apiKey`） |
| 平级会话 | `PeerSession` | 执行体自己开出的另一段会话，靠血缘记身份 | 兄弟会话、父子会话、子 agent |
| subagent | `subagent` | 执行体在一次工具调用里同步派出去的那个执行体，历史不落库 | 子 agent、子 Agent |
| 活物 | — | 生命周期与进程或某个实体绑定的对象，没有表 | 运行时、实例、状态机 |
