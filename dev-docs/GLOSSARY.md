# 名字

散文里出现的名字只有一种来源：代码里的原文 —— 类型、方法、字段、文件名、命令名、配置键。
中文只负责把句子连起来，不生产名字。

本文件记两件事：一个名字对应哪段代码，以及哪些叫法是错的。第三列是禁用词表的出处 ——
凡是列在那里的写法（包括曾经用过的中文译名），一律不再使用。

| 名字 | 是什么 | 不许叫 |
|---|---|---|
| `Workspace` | 一个工作目录及它的身份。一行记录，`cwd` 唯一 | 工作区、空间、repo |
| `Session` | 一段持续的身份与历史。一行记录，永远存在 | 对话、聊天、thread、conversation |
| `Message` | 一段 `Session` 里的一条内容（core 的类型），整条存在 `payload` | 话、聊天记录、条目 |
| `AgentDefinition` | 用户配置里的模板：模型、参数、系统提示 | 助手、智能体、agent |
| `Agent` | 一段 `Session` 上活着的那个对象，与 `Session` 1:1，可能不存在 | 执行体、实例、机器人、worker、驱动者 |
| `Scope` | 按目录存活，持有 MCP 连接、插件与工具；与 `Workspace` 1:1 | 能力容器、上下文、环境、沙箱 |
| `Asset` | 上传的文件：库里的行 + 磁盘上的字节 | 素材、附件、图片、文件 |
| `Handoff` | 上下文装不下时换取新记忆的动作 | 迁移、归档、压缩（压缩是它的实现手段之一） |
| `Question` | 宿主向用户发问并等待回答的进程内对象，不落库 | 询问、弹窗、确认框 |
| `Notice` | 一条短消息，落库，有寿命 | 提示、toast |
| `runtime.agent.send` | 宿主的一条 procedure：把一条内容放进那段 `Session` 的 `Agent` 的 `inbox`。不唤醒它，也不等它跑完 | 递话、投递、发送 |
| `Agent.send()` | 把一条内容放进自己的 `inbox` 就返回，不等它跑 | 递话、投递、push |
| `Agent.sendAndWait()` | 同一个动作，投进去之后等到这一批跑完；只对一次性 `Agent` 有效 | 递话、同步发送 |
| `AgentRuntime.post()` | 一个 `Agent` 把自己的话交给另一段 `Session`（模型那一侧的工具叫 `post_message`） | 发话、发送、通知 |
| `inbox` | `Agent` 一条一条取走的队列，没取走的落库 | 收件箱、消息队列、缓冲区、待处理 |
| `asTakeAll()` | 外循环取走当前全部 `InboxEntry` 的那一次调用 | 取件、拉取、批处理 |
| `InboxEntry` | `inbox` 里的一条：带正文的，或者只是一把钥匙 | 条目、任务、工单 |
| `pauseOutput()` / `pauseInput()` | 关掉输出 / 关掉输入，不中止进行中的请求 | 暂停、挂起 |
| `abort()` | 中止进行中的请求并关掉输出，不销毁 `Agent` | 中断、取消、打断、停止 |
| `kill()` | 销毁 `Agent`；`Session` 的行与历史保留 | 杀死、关闭、结束、销毁 |
| `config` | 磁盘上人可编辑的文件。既不是库里的行，也不是活物 | 设置、选项、偏好 |
| `credential` | 宿主访问令牌：落库、带 hash、可吊销 | 凭证、密钥（密钥是模型端点的 `apiKey`） |
| `PeerSession` | 一个 `Agent` 自己开出的另一段 `Session`，靠血缘记身份 | 平级会话、兄弟会话、父子会话、子 agent |
| `subagent` | `Agent` 在一次工具调用里同步派出去的那个 `Agent`，历史不落库 | 子 agent、子 Agent、子代理、子执行体 |

「生命周期与进程或某个实体绑定的对象」这一类没有名字，也不要给它起 —— 活物、运行时、实例、
状态机都不是名字。

借来的词（`Scope` 之外的 `Session`、`Message`、FTS、WAL）业界已有，不解释，只在含义被本项目
收窄时记一行。
