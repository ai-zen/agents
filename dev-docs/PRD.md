# PRD（索引）

产品需求的唯一来源。本文件只是目录：正文按主题分册，一册一件事。

**读法**：先读 [`prd/00-frame.md`](prd/00-frame.md)（需求来源、八条硬规矩、命名）。它是全书的地基，别跳过。
其余各册按需要读：改哪一块，读哪一册。
