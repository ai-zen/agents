## 🧠 Key Decisions

- **文档只改「事实错」，不重写文风**：`desktop-design.md` 的旧协议词会让照文档写代码的人接错契约，那是 bug 级问题；排版与措辞留给下一轮（用户已说要统一收文案）。
- **测试口径写进 `architecture.md` 而不是单独 TESTING.md**：那条链的文档入口只有 `PRD.md` / `PLAN.md` / `architecture.md` 三份，多一份就多一个会腐化的地方。
- **删用例的判据是必要性不是速度**：生产零调用者的方法连用例一起删（先例列在 §11.3）；但便宜的契约守卫（`wire/*` 70 条共 0.07s）一条不砍 —— 删了省不下时间，只丢覆盖。
- **夹具降本的边界**：共享的只有库；服务实例 / 事件数组 / 时钟 / 假运行时每条重建；「关库再重开」的用例保独立实例（共享库的 `close()` 会拖垮整文件）。
- **本轮踩过的死路**：①`pkill -f "setup.mjs"` 会把自己的 shell 命令行也匹配掉（把自己杀了），要按 pid 杀或用不含目标串的命令；②想用 `:memory:` 省掉迁移——`dbWorker` 强制 `journal_mode=wal`，内存库直接抛错；③在 pty 里起 TUI 前若已有残留宿主占着 8790，本地模式会以 `EADDRINUSE` 失败而界面只说「15 秒内没就绪」。
