## 1. 产品是什么

一台电脑上常驻一个后台服务，承载"一段段对话"：它知道每段说到哪儿、存在哪里、属于哪个项目，也管着这个项目能用哪些技能、工具、MCP、模型。用户关掉窗口、换一个前端、换一台设备连回来，看到的都是**同一段对话、同一份历史**。

它说人话（错误原因、提醒、状态说明），并**自己做多语言**；同时把事实以结构化形状给出，不让前端靠解析句子猜原因。

**它提供能力，客户端提供交互**：服务端只保证"这个能力存在"，界面怎么摆是客户端的事。

## 2. 已定决策（锁定，不重开）

### 2.1 基础决策

| # | 决策 |
|---|---|
| L1 | **远程是一等场景**；不做任何兼容、不留余地：旧前端不保、旧目录旧代码全删、旧数据不迁移不识别；服务端、契约、前端同一版发布 |
| L2 | **对话存 SQLite**；二进制素材（图片/文件附件）落数据根下的 `assets/`，库里只存引用。故"数据只有一个落点"＝**一个数据根**（库 + assets），不是单个文件 |
| L3 | **提醒：手动清 + 持久化**；通知创建时带**持续时间**字段 —— 给秒数则到点自动消失，不设置则永久存在（只能手动清） |
| L4 | **对话寿命不跟连接走**：10 分钟无活动且没在跑才回收；没有活对话也没有连接后进程才退出 |
| L5 | **重连由客户端主动拉**（拉状态 + 按消息 id 拉消息，含流式中那条的部分内容）；**在线时服务端推送**，两者并存 |
| L6 | **id 一律服务端分配**；助手消息的 id 在请求发出**之前**分配 |
| L7 | **一段对话的身份创建时定死**：项目、助手、模型创建即定；临时换模型只在内存、不进库、重开回默认 |
| L8 | **生成状态必须完整**：连上 / 等首字 / 在想 / 在输出 / 在生成工具调用 / 在等哪几个工具 |
| L9 | **MCP 是 5 层链**：`<ws>/.mcp.json` → `<ws>/.ai-zen/mcp.json` → `<ws>/.agents/mcp.json` → `<aiZenDir>/mcp.json` → `~/.agents/mcp.json` |
| L10 | **不做 `Origin` 白名单** |
| L11 | **凭证靠复制 + 手动输入**；**可以有多串**（创建时带备注，权限相同，可单独吊销） |
| L12 | **不做账号 / 登录 / 按人分权限**（设备不是人，凭证多串不算破此条） |

### 2.3 本轮问答定下的

| # | 决策 |
|---|---|
| D1 | **会话有独立名字字段**（id 永不变、服务端分配），用户可改名 |
| D2 | **自动命名**：第一轮对话结束后、用户未改过名字则自动起名；带独立开关；用**"取名模型"配置项**；**原名＝创建时间**，起不出名就保持原名 |
| D3 | **临时对话**：一次请求跑一轮、结果返回后内存清空；无 id、不可 attach、不入库、不进列表；**只借 Scope，与 Workspace 无关** |
| D4 | **升级**：服务端检测版本号，确认升级真的完成（磁盘上的版本已更新）就**立即重启**，不等在跑的轮次；服务端不自装包 |
| D5 | **图片**：服务端提供**上传入口**；上限 20MB/张、4 张/条 |
| D6 | **图片模型保留**（SDK 能力），含默认图片模型 |
| D7 | **`@` 补全**：按需扫描（git `ls-files` 优先，非 git 用 glob 并排除 `node_modules/.git/dist`），20000 条 / 5s 超时 / 15s 缓存；未就绪要说话 |
| D8 | **文案与多语言**：服务端产出文案并**自己做多语言**；**语言挂在连接上**（`hello` 带可选 `language`，断开即忘），缺省用配置的默认语言（英文） |
| D9 | **Workspace 是一等公民**：id 由服务端分配、**cwd 不可变**；一个 Workspace 诞生一个 Scope；一个 Workspace 下可多个对话，对话**复用**该 Scope；搬家＝新 Workspace（无重定位、无自动发现） |
| D10 | **Workspace 的产生**：显式添加为主；普通对话遇到未登记的 cwd 时问一次是否登记为项目；临时会话不进这条线 |
| D11 | **删 Workspace＝连带删它名下的对话**，删前明说代价；**目录本身服务端永不碰** |
| D12 | **cwd 不存在**：Workspace 与对话照常存在、照常可看；服务端只报"目录已不存在"这个事实，**是否只读由客户端判断** |
| D13 | **侧栏排序**：默认按**创建时间倒序**，可**手动置顶**；活动/打开/改名都不改变顺序 |
| D14 | **一段对话同时只跑一轮**；再来请求直接拒绝并说明"正忙"；中止是用户的显式动作（不排队、不自动打断） |
| D15 | **崩溃恢复**：边流边写，在途消息以 `Aborted` 落库；装载/重启后复用 core 的 `reconcileAbortedToolRounds(fill)` + `reconcileAbortedMessages(keep)` 修复；存储层必须保留 `status`/`omit` |
| D16 | **搜索**：按名称、按聊天内容全文、按 Workspace 过滤（中文分词成本接受） |
| D17 | **删除对话＝硬删**，删除前警告；图片按引用清理 |
| D18 | **交接/迁移后开一段新对话**（同 Workspace、同助手），内含系统提示 + 交接文档摘要；旧对话完整保留可回看 |
| D19 | **交接文档写进项目**：`<cwd>/.ai-zen/handoffs/` |
| D20 | **临时换模型拒绝降级**：历史里有图且新模型不支持视觉 → 不允许换，并说明原因 |
| D21 | **配置只能走服务端 API** 读写（校验与生效点都在服务端） |
| D22 | **问题对象**：有状态、有生命周期、可持久化；多端看同一会话看到同一个问题；交接在**对话停下之后**触发 |
| D23 | **越过硬线两端都拒绝**（客户端拒绝、服务端也拒绝），问题对象继续挂着 |
| D24 | **撤回**：撤回到任意用户消息之前，其后消息硬删，被撤回内容回填输入框；**消息分叉列为后续能力** |
| D25 | **端口**：默认端口 + 启动参数 + 配置文件，优先级 参数 > 配置文件 > 默认端口；不做发现文件 |
| D26 | **连接管理归客户端**：记住上次连接、首次/失败进连接屏、可启动本地服务或连远程（地址 + 密钥）、可更换 |
| D27 | **阈值配在哪＝不问**（属 SDK 的 `AppConfig` 事实：模型级 `tokenThresholds{handoff,guard}`） |

## 3. 判定落点的尺子

| 代号 | 含义 |
|---|---|
| **S** | 服务端承接。判据：远程前端**拿不到**这个事实（磁盘、进程内存、数据库），或它必须是"同一份真相" |
| **C** | 客户端自己做。判据：**本机**能力（终端、剪贴板、编辑器、配色、布局、交互），换一台设备本就该不同 |
| **S+C** | 服务端出事实，客户端出表现 |
| **X** | 不要 |

底层理由（后面反复引用）：①远程拿不到 ②一份真相 ③不丢 ④前端不做算术 ⑤**服务端给能力、客户端给交互**。

## 5. 不做的事

| 不做 | 理由 |
|---|---|
| 兼容旧版前端 / 双接口 / 为旧版保留字段 | L1：一套就是一套 |
| 迁移或识别旧数据 | L1：新库从空开始 |
| `Origin` 白名单 | L10 |
| 账号、登录、按人分权限 | L12 |
| 用凭证区分"人" | 设备不是人；凭证多串只是为了能单独吊销 |
| 自动重连多次、服务端补发事件 | L5：重连是客户端的事；在线才推 |
| 跨设备共享"语言偏好" | D8：语言挂连接，断开即忘 |
| 消息分叉 | D24：列为后续能力 |
| 服务端替用户决定"要不要迁移" | D22：问，且问的对象可持久化 |

## 6. 代码里几处容易搞错的事实

| 容易记成 | 实际 |
|---|---|
| MCP 是两个作用域、两层 | 合并是 **5 层链**；能编辑的才是 2 个作用域 |
| 附件上限 8MB 一条 | 图片 **20MB/张**、**4 张/条**；粘贴文本 256KB（本机限制） |
| 对话有"名字"和"标题"两种 | CLI 里名字就是 id；名字字段是新加的（D1） |
| 迁移会把旧历史剔掉 | CLI 是 `prune`；本稿改为**开新对话、旧的完整保留**（D18） |
| 通知只有一种 | 三档语气 + 持续时间字段（L3） |
| 子 Agent 不受上下文限制 | 与主 Agent 同源，递归传染到孙级 |
| 图片模型没有使用者 | SDK 能力，本稿保留并补上生成链路（D6） |
